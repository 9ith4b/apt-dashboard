# ADR 0001：M0 采用模块化单体

- 状态：已接受
- 日期：2026-08-08

## 背景

APT Hunter 需要覆盖采集、正文抽取、事件识别、威胁钻石模型拆解、审核、持续跟踪和狩猎查询。当前阶段首先要验证端到端数据闭环，尚不需要为每个能力单独维护一套服务。

## 决策

M0 采用 React 单页应用、FastAPI 模块化单体、Celery 异步任务、PostgreSQL、Redis 和 MinIO。后端模块在代码和数据边界上保持清晰，但作为一个 API 部署单元和一组共享 Worker 运行。

## 结果

- 开发、部署和本地排障路径短，适合快速建立第一个垂直切片。
- 采集与分析任务仍通过队列解耦，后续可按吞吐量独立拆分 Worker。
- 若某个模块出现明确的扩缩容、隔离或团队所有权需求，再通过后续 ADR 决定是否拆成独立服务。
