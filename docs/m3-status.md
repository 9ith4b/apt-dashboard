# M3 字段级复核与威胁事件沉淀状态

更新时间：2026-08-08

## 已交付

### 字段级人工修正

- 钻石模型四个维度均支持逐项“保留/排除”。
- 支持人工补充实体名称、类型、置信度和证据说明。
- 机器抽取结果保持只读，不会被人工结果覆盖。
- 审核时保存独立的最终字段快照、分析员备注、审核人和版本号。
- 每次决定写入 `analysis_revisions`，可通过 API 查看历史修订。
- 继续使用乐观锁，过期页面无法覆盖较新的审核结果。

### 威胁事件沉淀

- 审核通过时，在同一数据库事务内创建或更新 `ThreatEvent`。
- 每篇材料只归属一个威胁事件，避免重复批准产生重复事件。
- 事件保留标题、摘要、自动/人工置信度、首次和最近观测时间。
- 事件钻石模型仅聚合分析员确认后的实体，不包含已排除的误报。
- 事件详情保留原始报告来源、发布时间、相关性及原文链接。
- 新增真实事件列表/详情页；没有已确认事件时提供清晰的空状态和审核入口。

## API 概览

- `GET /api/v1/reviews/{report_id}/revisions`：获取版本化审核修订。
- `POST /api/v1/reviews/{report_id}/decision`：提交最终钻石字段、事件标题、人工置信度与审核决定。
- `GET /api/v1/events`：获取已沉淀威胁事件列表。
- `GET /api/v1/events/{event_id}`：获取事件钻石模型与关联证据材料。
