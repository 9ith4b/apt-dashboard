# M7 攻击组织持续跟踪洞察与导出状态

更新时间：2026-08-08

## 已交付

### 自定义周期与等长对比

- 本月、本年、全部和自定义日期继续作为统一筛选入口，同一范围同时约束组织列表、事件、趋势、变化、摘要与导出。
- 系统自动选择趋势粒度：31 天以内按日、32～180 天按周、超过 180 天按月。
- 每个周期与紧邻的上一等长周期比较，返回本期/上期事件数、绝对变化和可计算时的百分比变化。
- 全部模式会使用该组织首尾已确认事件日期作为周期边界；无事件时保持明确空状态。

### 变化集合

- 从已确认事件的人工复核钻石实体和 ATT&CK 证据映射计算能力/恶意软件、基础设施、技术和受害目标集合。
- 分别展示本期新增和本期未再出现项，不把“未再出现”错误解释成能力或基础设施已经失效。
- 当前与上一周期使用相同长度，避免月、年或自定义范围混用造成无意义对比。

### 摘要与导出

- 可按当前日期范围生成规则驱动摘要草稿，包含事件变化、四类新增/未再出现亮点与三项必要限制说明。
- 摘要返回支撑事件 ID 和 Evidence ID，并标记为 `draft`；系统不会自动发布分析结论。
- JSON 导出保留完整周期、对比、趋势、变化和事件结构；CSV 导出包含事件及变化记录，使用 UTF-8 BOM 兼容常见表格工具。

## API 概览

- `GET /api/v1/actors/{actor_id}/tracking`：返回周期边界、自动粒度、等长对比、趋势、四类变化和事件。
- `POST /api/v1/actors/{actor_id}/tracking/summary`：生成带支撑 ID 和限制说明的摘要草稿。
- `GET /api/v1/actors/{actor_id}/tracking/export?format=json|csv`：导出当前日期范围结果。
