# 产品需求

## 1. 产品目标

APT Hunter 将分散在安全厂商博客、RSS、公开网页和社交媒体中的 APT 攻击信息集中到一个可检索、可审核、可持续跟踪的工作台。系统不只是新闻阅读器，而是把原始报道处理为有证据支撑的结构化攻击事件。

首版成功标准：

- 分析员可以在一个界面查看高相关内容，不必逐个访问数据源。
- 同一事件的重复报道能够聚合，同时保留各篇报道及其证据。
- 系统能给出攻击钻石四个维度的候选结果，并清楚区分“自动提取”和“人工确认”。
- 分析员可以持续跟踪指定 APT 组织，查看任意日期范围内的攻击事件和行为变化。
- Observable 只有经过证据审核后才能提升为 Indicator。
- 任意自动结论都可以定位回原文片段。

## 2. 目标用户

MVP 面向单名威胁情报分析员或日常狩猎人员。系统暂不提供团队角色和审批层级，但所有修改保留操作记录，为未来协作功能预留基础。

## 3. 核心场景

### 3.1 发现新事件

用户进入情报流，查看按相关性排序的新内容。列表应解释为什么与关注对象相关，例如“命中 Lazarus 别名”“包含新增基础设施”“与虚假招聘 TTP 相似”，而不是只显示标题。

### 3.2 审核钻石模型

系统从报道中生成攻击者、能力、基础设施和受害目标候选。用户在原文证据旁接受、修改或拒绝候选，并为关系设置置信度。

### 3.3 合并重复报道

多家厂商可能描述同一攻击。系统先完成报道级去重，再提出事件合并候选。用户确认后，多篇 Report 关联到同一个 Threat Event，但报道数量仍单独统计。

### 3.4 持续跟踪 APT 组织

用户关注 Lazarus、APT28 等组织，按月、年或自定义日期范围查看：

- 去重攻击事件数量和报道数量；
- 新出现的恶意软件、基础设施、ATT&CK 技术和目标行业；
- 与上一可比周期相比的行为变化；
- 高置信事件、待审核候选和证据不足项；
- 可导出的阶段研判摘要。

### 3.5 IOC 狩猎

用户搜索 IP、域名、URL、邮箱或文件哈希，查看出现过的报道、事件、富化结果和时间线。系统不能因为字符串出现在文章中就自动将其视为恶意 Indicator。

## 4. 端到端示例：Lazarus 虚假面试

1. RSS 收到安全厂商文章，X 和 Telegram 出现同一研究的转发或补充信息。
2. 系统归一化 URL、计算内容指纹，并识别这些内容可能描述同一事件。
3. 规则提取域名、URL、邮箱、文件哈希；别名词典识别 Lazarus、Hidden Cobra 等候选。
4. 语义分析提取“伪装招聘人员”“安排视频面试”“诱导执行代码”等能力和行为。
5. 系统生成事件候选，并把每个字段绑定到原文证据。
6. 分析员确认攻击者归因，拒绝仅由转发文案推断出的无证据关系。
7. 经确认的事件进入 Lazarus 画像、Campaign 时间线和持续跟踪统计。
8. 有明确恶意用途的域名可从 Observable 提升为有有效期的 Indicator。

## 5. 功能范围

### MVP 包含

- RSS/Atom、目标网页、X API v2、Telegram 公开频道适配器；
- 数据源管理、运行状态、手动同步与失败重试；
- 正文抽取、语言识别、报道去重、APT 相关性评分；
- IOC、组织别名、恶意软件、ATT&CK 技术、行业和地区候选提取；
- 事件聚类、钻石模型、证据审核和审核队列；
- 攻击者画像、Campaign 时间线、IOC 狩猎和关注规则；
- 月、年、自定义日期的组织持续跟踪；
- JSON、CSV 和分析报告导出；
- 单用户本地登录、审计日志、备份与健康检查。

### MVP 不包含

- 企业 SSO、多租户和复杂团队权限；
- 样本动态沙箱和恶意软件逆向平台；
- 自动执行封禁、隔离等响应动作；
- 无人审核的确定性攻击者归因；
- 绕过登录、付费墙、验证码或平台访问控制的采集；
- 移动端原生应用。

## 6. 质量与非功能目标

- 正常规模下，列表查询 P95 小于 800 ms，详情查询 P95 小于 1.5 s。
- 采集和分析采用异步任务，外部服务异常不得阻塞主界面。
- 每个异步任务应幂等，并能显示当前阶段、最近错误和重试次数。
- 原始内容、结构化结果和证据之间具备可追踪关系。
- 所有时间在数据库中保存 UTC，按用户时区展示。
- 密钥不得进入数据库明文字段、前端包、日志或导出文件。

## 7. 验收指标

- 对标准测试集中的 IOC 类型，确定性提取召回率不低于 95%。
- 所有已发布事件的钻石字段均有至少一条 Evidence，或被明确标记为“分析员判断”。
- 同一规范 URL 或相同正文不会重复生成 Report。
- 事件合并操作可撤销，且不会丢失原始报道。
- 自定义日期筛选同时影响趋势、列表、变化统计、摘要和导出。
- 未配置某个社交媒体凭据时，其他采集源和分析功能仍可正常工作。
