# 交互与设计系统

## 1. 设计方向

采用“深色情报工作台 + 浅色分析画布”的组合。外壳负责导航、状态和全局操作；浅色画布承载长文本、图表、钻石关系和证据审核，减少连续阅读疲劳。

设计原则：

- 证据优先：结论旁直接显示来源和证据，不把解释藏在二级页面。
- 状态清晰：自动候选、人工确认、已拒绝和已过期必须可区分。
- 少用卡片堆叠：以连续表面、分组标题和行分隔表达层级。
- 危险操作克制：实体合并、事件合并和 Indicator 提升必须二次确认并支持撤销。
- 图表可下钻：图中的数值都能查看构成它的事件或报道。

## 2. 设计令牌

### 颜色

| Token | 建议值 | 用途 |
| --- | --- | --- |
| `--background` | `#F6F7FB` | 浅色工作区背景 |
| `--foreground` | `#172033` | 主文字 |
| `--sidebar` | `#101724` | 应用外壳 |
| `--primary` | `#6D5CE7` | 主操作、选择态 |
| `--confirmed` | `#0F9F82` | 已确认、健康 |
| `--candidate` | `#D99017` | 候选、待审核 |
| `--malicious` | `#D64A5D` | 恶意、高风险 |
| `--muted` | `#667085` | 次要文字 |
| `--border` | `#D9DFEA` | 边框与分隔 |

颜色不能作为唯一状态信号，必须配合图标、标签或文本。

### 字体与密度

- 中文正文：Noto Sans SC；拉丁字符和数字：Inter。
- 页面标题 24/32，区块标题 16/24，正文 14/22，辅助信息 12/18。
- 表格默认行高 44 px；长文本审核场景允许舒适密度 52 px。
- 内容最大宽度不强制限制，正文阅读列控制在约 80 个中文字符以内。

### 圆角与阴影

- 输入框、按钮和 Badge 使用 6–8 px 圆角。
- 弹窗和 Sheet 使用 10–12 px 圆角。
- 仅浮层、拖拽对象和当前焦点对象使用阴影。

## 3. shadcn/ui 映射

| 场景 | 组件 |
| --- | --- |
| 应用导航 | `Sidebar`、`Command`、`Breadcrumb` |
| 筛选 | `Select`、`Combobox`、`Popover`、`Calendar` |
| 列表 | `Table`、`Badge`、`DropdownMenu`、`Pagination` |
| 详情 | `Tabs`、`Accordion`、`Sheet`、`ResizablePanel` |
| 审核 | `Textarea`、`AlertDialog`、`ToggleGroup`、`Tooltip` |
| 状态反馈 | `Alert`、`Toast`、`Progress`、`Skeleton` |
| 配置 | `Form`、`Switch`、`Input`、`Checkbox` |

业务组件应在 shadcn 基础上组合，不直接修改底层组件的公共行为。

## 4. 关键交互

### 证据定位

- Evidence 标签显示来源、页内位置和置信度。
- 点击后打开原文面板并高亮对应片段。
- 同一结论有多条证据时按直接证据、间接证据和反证分组。
- 原文发生重新抓取时保留旧版本，证据继续指向创建时的内容版本。

### 审核状态

| 状态 | 含义 | 可执行操作 |
| --- | --- | --- |
| `candidate` | 自动生成，未审核 | 接受、修改、拒绝 |
| `confirmed` | 用户确认 | 修改、重新打开 |
| `rejected` | 明确拒绝 | 恢复为候选 |
| `superseded` | 被新版本或合并结果替代 | 查看替代对象 |

### 置信度

- 置信度是 0–100 的数值，界面同时显示低、中、高标签。
- 自动评分和人工评分分开保存，最终展示值必须注明来源。
- 攻击者归因不能仅凭别名命中或单一 TTP 达到“高”。

### 自定义日期

- 使用 `Popover + Calendar(mode="range")`。
- Popover 中显示起止日期、快捷范围、时区和取消/应用按钮。
- 未完整选择起止日期时禁用应用。
- 日期范围超过产品允许上限时给出内联提示，不静默截断。
- 应用后把 `from`、`to` 和 `timezone` 写入 URL。

### 合并与撤销

- 合并前并排展示保留对象、候选对象、字段冲突和受影响关系。
- 合并只创建新版本和重定向关系，不物理删除原对象。
- 审计日志中记录操作前后差异，允许从详情页撤销。

## 5. 图表规范

- 事件数使用实线，报道数使用虚线或次要柱形，图例明确区分。
- 图表 Tooltip 同时显示当前桶起止时间、事件数、报道数和确认状态分布。
- 时间序列缺失日期显示 0，不跨空白点绘制误导性趋势。
- 行业、技术和恶意软件排名必须显示统计样本数。
- 所有图表提供对应表格视图，便于键盘用户和导出。

## 6. 响应式与可访问性

- 主要设计目标为 1440 px 桌面；最低支持 1024 px。
- 小于 1200 px 时右侧证据区转为 Sheet，侧边栏默认收起。
- 钻石画布不能仅依赖拖拽，节点和关系同时提供列表视图。
- 所有交互控件可通过键盘到达，焦点样式清晰。
- 正文和背景对比度满足 WCAG 2.1 AA。
- 动画遵循 `prefers-reduced-motion`。
